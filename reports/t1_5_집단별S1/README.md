# T-1.5 집단별 S1: 집단마다 그 집단의 1인세대 비율로 구조 축 바꿔 보기 (대안 비교)

[← 전체 리포트 목록](../README.md)

지금 LINK-Radar 구조 축 S1은 **동 전체 1인세대 비율(전 연령)** 하나라 고령층·중장년 남성이 같은 동을 후보로 받습니다. 이 리포트는 S1을 **집단마다 그 집단의 1인세대 비율**로 바꾸면 무엇이 달라지는지 봅니다. **공식 등급(rules-v1.1, [R-2](../r2_위험도결과/README.md))은 바꾸지 않습니다.** 아래는 모두 'rules-v1.1 vs 집단별 S1 대안' 나란히 비교입니다. 스크립트는 [`notebooks/t1_5_cohort_s1.py`](../../notebooks/t1_5_cohort_s1.py)입니다.

- 다른 집단은 지금 S1과 차이가 작습니다. 집단별 S1이 시민생활과 더 잘 맞는다고 말할 만한 차이는 없습니다.

사전 등록 규칙: 조건 A = 중장년 여성 S1 상위 30% 동 중 기존 동 단위 집단(고령층·중장년 남성·50~69세 남성) 상위 합집합에 없는 동이 2곳 이상, 조건 B = 기존 세 집단 S1과의 ρ가 모두 0.8 미만. 한 도시라도 기준월 3개 모두 A·B → 추가 권고 / A 또는 B만 → 참고 칸 / 둘 다 아님 → 추가 안 함. 전체 칸은 [`Q4_판정.csv`](Q4_판정.csv).

- **판정: 추가하지 않음.** 중장년 여성 상위 동은 기존 집단 상위 동에 거의 다 들어 있고, S1 순위가 중장년 남성과 거의 같습니다. 새 집단을 만들면 '새 동'이 아니라 '같은 동의 다른 대상'이 늘어납니다(T-2 5절과 같은 결론).

## 8. 정리

- 집단별 S1로 바꾸면 **고령층 후보가 일부 다른 동으로 옮겨 가고**, 고령층 ↔ 중장년 남성 겹침이 '완전히 같음'에서 '대부분 같음'으로 줄어듭니다. 등급이 바뀐 행은 566행 중 22행입니다.
- 청년 남성의 음의 상관은 집단별 S1에서도 남아 도시 단위 안내를 유지합니다. 중장년 여성은 사전 등록 판정대로 더하지 않습니다.
- 독립 기준에서는 집단별 S1이 장애인 비율과 더 맞지만 동 규모에 더 끌립니다. 지금 S1보다 낫다고 말할 근거는 없습니다.
- 그래서 이 결과는 **공식 등급을 바꾸지 않고**, 후보 카드의 맥락 칸('이 집단의 1인세대 비율 순위')으로 붙이는 것을 검토할 재료입니다. 등급 규칙에 넣으려면 rules 판을 올리는 별도 사전 등록이 필요합니다.

## 사전 등록과 다른 점 · 한계

- 사전 등록에서 바꾼 기준은 없습니다. 독립 기준 채점과 S1 상관에 중장년 여성 행을 참고로 더 적었고, 시민생활 상관에 순열 p를 더 적었습니다(판정에는 청년 남성 행만 씀).
- 주민등록 1인세대 ≠ 실제 1인가구입니다. 1인세대의 성·연령은 혼자인 세대주의 것입니다.
- 성·연령별 1인세대수의 과거 공개 시점은 확인하지 않았습니다(세대원수별 자료와 같다고 가정).
- 동 22·25개라 ρ의 불확실성이 큽니다. 시민생활은 SKT 추정이라 탐색입니다. 실제 고립 정답은 없습니다.
