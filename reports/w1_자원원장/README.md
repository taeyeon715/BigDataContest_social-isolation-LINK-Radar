# W-1 자원 원장 보강

[← 전체 리포트 목록](../README.md)

복지자원 원장에 **상태 칸**(이용 방법, 좌표 상태, 자격 기준, 운영 상태, 운영 시간, 휴일 운영, 서비스 범위)을 붙였습니다. 목적은 "가장 가까운 시설"이 아니라 **필요에 맞고 실제 이용 가능한 자원**을 출처와 함께 고르는 것입니다.

- 원본 `external/resources/복지자원_원장.csv`는 그대로 두고, 칸을 붙인 원장을 `복지자원_원장_v2.csv`로 따로 만듭니다(기존 칸·값·행 순서 동일). EDA-4 결과는 바뀌지 않습니다.
- 칸을 채우는 규칙은 [`src/bigcontest/resources/ledger.py`](../../src/bigcontest/resources/ledger.py) 맨 위에 있습니다. 원장에 있는 칸만 보고 정하며, 알 수 없으면 **미상**으로 둡니다(추측하지 않음).
- 손으로 고친 값은 [`정정_기록.csv`](../../external/resources/정정_기록.csv)에 새 줄로 쌓습니다(덮어쓰지 않음).
- 검사 결과: 오류 0건. 주의: 확인일이 날짜가 아닌 행(재확인 필요) 32건
- 보강 자원 **323건**을 원래 원장 뒤에 붙였습니다(휴일 운영 약국·병의원·응급의료기관, 복지로 제도·사업, 노인맞춤돌봄 수행기관, 사람 자원). 7절에 출처·건수, 6절에 남은 것을 적었습니다.
- **두 도시 목록은 구성이 달라**(강남은 경로당 포함, 춘천은 행정복지센터·보건지소 포함) 도시끼리 수를 비교하지 않습니다.

## 1. 원래 원장 745건 vs 거리 계산 738건

## 5. 매칭 예시

순서: 출처·확인일(G-07) → 관할 → 대상 연령·자격 → 필요 유형 → 운영 상태 → 거리/전화형. 자격을 모르면 "확인 필요", 전화형은 거리와 무관, 좌표 없는 거점은 "위치 확인 필요", 관할 밖(권역 외) 물리 거점은 최대 "확인 필요". 거리는 행정동 중심점에서 잰 직선거리입니다.
추천은 **제외 규칙(확인일·출처 없음, 관할 밖 물리 거점)을 먼저 적용한 뒤 상위 5건**을 고릅니다. 빈자리는 다음 자원으로 채우고, 건너뛴 자원은 "확인할 자원"으로 사유와 함께 보입니다. 같은 분류는 상위에 2곳까지만 둡니다(경로당 5곳만 나오지 않게). 위기 전화(자살예방·정신건강 위기상담)는 순위에 넣지 않고 맨 아래 **"위급 시 안내"**로 따로 둡니다. 고령층 안부·관계는 노인맞춤돌봄서비스(제도) → 행정복지센터 → 노인맞춤돌봄 수행기관 → 경로당·사람 자원 → 노인 돌봄·안전 확인 → (거점 원거리형이면 위기 전화가 아닌 전화형) → 찾아가는 서비스 → 노인복지관 순서입니다. 필요 유형이 여럿이면 유형마다 가장 앞 자원을 하나씩 먼저 넣고 나머지를 순서대로 채웁니다(연휴: 휴일 약국·의원 + 안부 전화 + 생필품 창구). 연휴(달력 공백형)에는 휴일 운영이 '예'인 곳을 앞에 둡니다.
