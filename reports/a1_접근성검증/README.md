## 출처와 범위

- 춘천시 공식 복지포털의 2026-05-01 경로당 목록 372곳을 원본 XLSX에서 추출했습니다. 2025년 371곳 집계와 기준시점이 다릅니다.
- 중복 주소를 합친 365개 검색어를 도로명주소 검색·좌표 도구로 대조했습니다. 기관에 연락하거나 유료 LLM을 호출하지 않았습니다.
- 372곳 중 326곳은 좌표를 사용할 수 있습니다. 46곳은 좌표 없음·미매칭·원문 주소 주의 표시로 거리 계산에서 제외하고 위치 확인 필요로 남겼습니다. 좌표가 있는 곳도 실제 운영·휴일 개방·개별 이용 가능성은 미확인입니다.
- 원장은 1,068 → 1,440건입니다. 기존 745건의 원본 칸과 순서를 보존하고 보강 목록을 별도로 합칩니다.
- 2025 생활 신호에 2026 현재 원장을 결합한 시연이며, 당시 가용 자료로 한 사전 예측 결과가 아닙니다.
