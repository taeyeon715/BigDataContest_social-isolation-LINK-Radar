# EDA-2 통신 기초

[← 전체 리포트 목록](../README.md)

SK텔레콤 유동인구로 강남·춘천의 **동네 구조**를 봅니다. 값은 하루 평균 체류량(보정된 추정값)이고, 6개월 평균 기준입니다.

> 유동인구는 그곳에 머문 사람이지 주민이 아닙니다. 특히 강남은 출퇴근 인구가 많습니다.


## 1. 도시별 성·연령 구성


![도시 구성](figs/f01_city_composition.png)

- 60대+ 비중: 강남 18.9%, 춘천 24.7%
- 20·30대 비중: 강남 34.7%, 춘천 26.6%
- 두 도시는 성격이 많이 다르므로 지표는 **도시 안에서 순위나 표준화**로 비교합니다.

## 4. 주거형 vs 낮 활동형 격자

심야/낮 비율로 격자를 셋으로 나눴습니다(도시마다 상위 1/3 = 주거형, 하위 1/3 = 낮 활동형). 강남의 낮 활동형은 대부분 업무·상업지이고, 춘천의 낮 활동형은 농경지·관광지·도로처럼 낮에만 사람이 있는 곳입니다.

| 도시 | 형 | 격자 수 | 체류량 비중 | 60대+ 비중 | 20·30대 비중 |
|---|---|---:|---:|---:|---:|
| 강남 | 주거형 | 223 | 7% | 23.7% | 27.9% |
| 강남 | 혼합 | 222 | 25% | 21.9% | 30.7% |
| 강남 | 낮 활동형 | 223 | 68% | 17.2% | 36.9% |
| 강남 | 상관(심야/낮 ↔ 60대+) | | | ρ = 0.51 | |
| 춘천 | 주거형 | 930 | 75% | 23.8% | 27.0% |
| 춘천 | 혼합 | 930 | 19% | 26.5% | 25.9% |
| 춘천 | 낮 활동형 | 930 | 6% | 26.2% | 25.6% |
| 춘천 | 상관(심야/낮 ↔ 60대+) | | | ρ = 0.16 | |

- 강남은 주거형 격자에 60대+ 비중이 높고 낮 활동형(업무·상업지)에 낮습니다. **강남에서 고령 관련 지표는 주거형 격자 위주로 보는 것이 출퇴근 인구를 덜 섞는 방법**입니다.
- 춘천은 이 구분이 고령 비중과 잘 연결되지 않습니다. 춘천은 동지역과 읍·면을 먼저 나눠서 봅니다.

## 정리

| 발견 | 설계에 주는 의미 |
|---|---|
| 두 도시의 성·연령 구성이 크게 다름 | 지표는 도시 안에서 순위·표준화 |
| 강남은 주거형 격자에 고령 비중이 높음 | 강남 고령 지표는 주거형 격자 위주 |
| 춘천은 주거형 구분이 고령과 무관, 읍·면 구분이 중요 | 춘천은 동/읍·면 먼저 분리 |
| 12월 하루 리듬 변화는 모든 지역 공통 | 리듬 변화는 신호가 아니라 계절 효과 |
| 춘천 읍·면은 겨울에 체류량이 크게 줄어듦 | 계절 공동화 후보. 방문객 효과 분리 필요 |
| 고령 비중 자체는 위험 신호가 아님(탐색 EDA 결론) | 이 리포트의 60대+ 비중은 '구성' 설명용 |
