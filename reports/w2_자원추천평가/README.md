# W-2 자원 추천 평가 (작은 정답 세트)

[← 전체 리포트 목록](../README.md)

복지자원 추천이 미리 적은 기준대로 자원을 고르는지 **(동 × 집단 × 필요 유형) 30쌍**으로 봅니다. 정답 규칙·쌍은 [`configs/resource_eval.yaml`](../../configs/resource_eval.yaml)에, 정답 세트는 [`정답세트.csv`](정답세트.csv)에 있고 **추천 결과를 보기 전에 커밋**했습니다(규칙 → 정답 → 평가 순서, git 기록으로 확인).

**방법을 정직하게**
- 정답은 팀이 공개 정보(복지자원 원장 v2 의 공개 출처 칸: 유형·대상·관할·휴일 운영·좌표·확인일)에 규칙을 적용해 만든 것입니다. 담당자가 자원마다 전화·현장으로 확인한 정답이 아닙니다.
- 정답 규칙은 추천 코드(`resources/match.py`, `configs/need_types.yaml`)를 옮겨 쓰지 않고 따로 적었습니다. 그래도 같은 원장 칸을 쓰므로 이 평가는 "원장이 맞다면 추천이 기준에 맞게 고르나"를 보고, 자원이 실제로 도움이 되는지는 보지 않습니다.
- **상위 5개 충족도 (k-정규화 Recall@5, 분모 min(5, 정답 수))** = 상위 5개 중 정답 수 ÷ min(5, 정답 수). 추천 칸이 5개뿐이라 그 안에서 채울 수 있는 만큼 채웠나를 봅니다. 정답이 5개보다 많으면 정답의 일부만 맞혀도 1이 될 수 있어 **"정답의 몇 %를 찾았다"는 뜻이 아닙니다.**
- 정답 전체 재현율 = 상위 5개 중 정답 수 ÷ 정답 수 (정답 전체 기준). 정밀도@5 = 상위 5개 중 정답 수 ÷ 추천 수. Hit@5 = 정답이 하나라도 든 쌍 비율.
- 부적격 추천 = 상위 5개 중 다른 시·구, 대상 연령 밖, 다른 관할 동, 운영 중단, 연휴인데 휴일 미운영 자원 수.
- 이름 변경 기록: 처음 판(w2-1)은 첫 지표를 'Recall@5'라는 짧은 이름으로 적었습니다. 계산은 같고, 정답 전체 기준 재현율과 혼동되지 않도록 2026-10-14 외부 점검(K-03) 뒤 이름에 분모를 붙였습니다. 정답 전체 재현율은 이때 함께 적기 시작한 값입니다.

## 5. 한계

- 30쌍, 정답은 공개 원장 칸 기준. 운영 상태는 원장 전부 '미상'이라 운영 중단 자원은 걸러지지 않습니다(부적격 0이 '운영 확인'을 뜻하지 않음).
- 원장 좌표는 탐색용 지오코더 값이 대부분이라 거리 5km 기준의 경계 근처는 바뀔 수 있습니다.
- 정답 규칙의 거리·기능 기준도 팀이 정한 운영 기준입니다. 현장 담당자 정답(동별 실제 연계 기관)이 생기면 그 정답으로 다시 냅니다.
