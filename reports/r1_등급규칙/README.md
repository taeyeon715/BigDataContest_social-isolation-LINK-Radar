# R-1 후보·등급 규칙 평가 (rules-v1.1)

[← 전체 리포트 목록](../README.md)

후보 종류와 등급을 정하는 규칙을 [`configs/rules.yaml`](../../configs/rules.yaml) **rules-v1.1**로 고정하고, 두 도시 × 기준일 3개에서 결과를 냈습니다. 등급은 규칙 코드가 정하고 LLM은 정하지 않습니다. 후보는 행정동·생애단계 집단 단위이며 **사람을 판정하지 않습니다.**

- 임계값은 서울 시민생활을 보지 않고 정했습니다. 값과 근거는 rules.yaml 주석에 있습니다.
- 모든 후보에 `rule_id`·`rule_version`·근거 신뢰도·대응 종류가 붙습니다. 예: `L2-STRUCT-TRIGGER`, `L3-STRUCT-ACCESS-TRIGGER`.
- 기준일은 simulated_replay(가정 공개일)로 냈습니다. 접근성은 2026년 원장이라 "현재 원장 기준 접근성"으로 표시됩니다.
- **후보 수는 임계값에 따라 바뀝니다.** 아래 3장 범위와 함께만 말해 주세요.

## 2. 비교안 A~D: 통신·카드는 주민등록에 무엇을 더하나

같은 날짜·도시·집단·K(10)에서 쓰는 자료만 바꿨습니다. A = 주민등록 + 달력, B = A + 통신(구성·계절), C = B + 카드(시점·이탈), D = C + 자원(접근성).

| 비교안 | 쓰는 근거 | 후보 수 | 예정된 점검 | 예상 밖 이탈 | Level 2 이상 | Level 3 | 판단 보류 | 잘못된 단위 주장 | 필수 근거 누락 후보 | Top-10 겹침률(A 대비, 평균) |
|---|---|---|---|---|---|---|---|---|---|---|
| A | 주민등록 + 달력 | 64 | 64 | 0 | 64 | 0 | 0 | 0 | 9 | 1.0 |
| B | A + 통신(구성·계절) | 64 | 64 | 0 | 64 | 0 | 0 | 0 | 0 | 1.0 |
| C | B + 카드(시점·이탈) | 89 | 64 | 25 | 66 | 0 | 16 | 0 | 0 | 0.98 |
| D | C + 자원(접근성) | 104 | 79 | 25 | 81 | 6 | 16 | 0 | 0 | 0.91 |

**읽는 법 (쉽게)**
- **'어디'는 주민등록이 정합니다.** 강남 동 순위는 A~D 모두 같습니다. 통신·카드는 동 단위 자료가 아니라 동 순위를 바꾸지 않습니다.
- **B(통신)**: 춘천 동절기 점검의 필수 근거(읍·면 겨울 변화)를 채워 부분 판정을 없앱니다. 그 자체로는 Level 3를 만들지 않습니다(Level 3 변화 0건).
- **C(카드)**: '언제'와 '아닌지'를 더합니다. 예상 밖 이탈 후보 행 25개(기준일·집단 합)가 새로 생기지만, 반증(연휴·도시 공통 변화·이탈 크기)을 거쳐 Level 2 이상은 2행입니다. **이 기준일들에서 C가 검토 목록을 바꾸는 폭은 작습니다.** 카드의 몫은 주로 "연휴 감소는 평소에도 있는 일인지"를 걸러 주는 반증입니다(D3: 춘천 20대 여성 경보 기각, 강남 고령층 '확인 필요').
- rules-v1.1부터 카드는 '아닌지'에 하나를 더합니다: 연휴 외지 손님 비중이 도시 공통 하락 경보의 다음 할 일을 바꿉니다(7-2, 춘천 추석 뒤 16건). 시간대 상대 리듬·업종 다양성은 맥락 칸입니다.
- **D(자원 접근성)**: 춘천 읍·면에서 Level 3(구조 + 접근성)이 생기는 단계입니다. 강남은 모든 동이 거점에서 가까워 바뀌지 않습니다.
- 잘못된 단위 주장(카드 도시 단위 신호로 동 하나를 지목): **0건**. 이탈 후보의 동 목록은 모두 '먼저 확인할 동(공유 맥락)'입니다.
- 미확인 자격 추천 수는 자원 추천 평가에서 셉니다. 이 표에는 없습니다.

### 7-7. 카드 '행 없음 = 0' 가정의 민감도

카드 daily()는 결제 행이 없는 (날짜, 코호트)를 0건으로 채웁니다. 이 칸을 0 대신 결측(미공급)으로 두고 경보를 다시 냈습니다.

|---|---|
| 패널 칸 (도시×연령×성×일) | 5152 |
| 행 없음 칸 | 0 |
| 경보 (0 가정) | 38 |
| 경보 (결측 가정) | 38 |
| 같은 경보 | 38 |
| 검토 결과 같음 | True |
