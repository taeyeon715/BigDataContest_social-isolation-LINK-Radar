# 프로젝트 진행 노트 — 주의사항 · 고려사항 (계속 업데이트)

주제: **사회적 고립 예방 및 대응을 위한 AI 에이전트** (2026 빅콘테스트 AI데이터 활용 분야)

진행하면서 알게 된 **주의해야 할 점, 고려해야 할 점, 내린 결정과 그 이유, 아직 풀지 못한 과제**를 단계 순서대로 기록합니다. 새 단계를 진행하거나 결정이 바뀌면 이 파일에 이어서 적습니다.

- 외부 데이터 해석에서 생기는 함정은 [외부데이터로_확인한_해석주의사항.md](외부데이터로_확인한_해석주의사항.md)에 따로 자세히 정리돼 있습니다. 이 노트는 그 내용을 포함한 **프로젝트 전체의 판단 기록**입니다.
- 수치는 모두 노트북 실행 결과 기준입니다. 근거 위치의 `01`~`04`는 노트북 번호입니다.

## 0. 전 단계 공통 원칙

| 원칙 | 이유 |
|---|---|
| **제공 데이터(SK·신한)가 결과의 중심이어야 함** | 심사 '데이터 근거 및 분석력(25점)'은 제공 데이터를 얼마나 적절히 썼는지를 봅니다. 외부 데이터는 기준점·보정·검증 역할로 둡니다. |
| **고립은 전 연령의 문제로 다룸** | 청년(고립·은둔), 중년(50~60대 남성 고독사), 노년(독거)이 모두 대상입니다. 노년 위주로 설계하면 청년·중년을 놓칩니다. |
| **집계 데이터라 개인 판정은 불가** | 모든 데이터가 비식별 집계입니다. 결과는 '동·집단 단위 우선순위'까지만 주장합니다. |
| **'일시적 감소 = 위험'으로 판단하지 않음** | 소비·유동 감소는 날씨·명절·방학·관광의 영향이 큽니다. 공식 기준과 지속성을 근거로 판단합니다. |
| **결과를 보고 설계를 고쳤다면 반드시 기록** | 같은 데이터로 고치고 평가하면 성능이 낙관적으로 나옵니다. 고친 이유와 전후 수치를 남기고, 설계를 동결한 뒤 따로 검증합니다. |
| **외부 데이터는 출처·시점·수집 방법·원본 파일을 함께 보관** | 대회 규정상 출처 명시와 원본 제출이 필수입니다. `external/` 폴더와 해석주의사항 md의 출처 표로 관리합니다. |
| **노트북은 앞에서부터 읽으면 이해되게** | 모든 섹션 제목 아래에 '왜 / 결과'를 적습니다. 단계는 00 → 01 → 02 → 03 → 04 순서입니다. |

## 1. 데이터 준비 · 품질 점검 (01)

| 구분 | 내용 | 결정 / 대응 |
|---|---|---|
| ⚠ 형식 | SK는 `|` 구분자·UTF-8, 신한은 탭 구분자·CP949로 서로 다릅니다. | `convert_to_csv.py`로 통일하고, 헤더는 정의서 한글명으로 바꿨습니다. |
| ⚠ 중복 | SK 12월 시간대·요일 파일은 모든 행이 정확히 두 번씩 들어 있습니다. | 변환 시 제거했습니다(규칙 ⑥). |
| ⚠ 엑셀 | `소지역코드`(20자리)는 엑셀에서 지수 표기로 깨집니다. 신한 데이터2(180만 행)는 엑셀 최대 행 수를 넘습니다. | 분석은 pandas로 하고, 코드는 문자열로 읽습니다. |
| ⚠ 범위 | SK에 인접 시군구 경계 격자 60개가 섞여 있습니다. | 강남·춘천만 분석합니다(규칙 ⑤). |
| ⚠ 단위 | 결제건수는 실제 건수가 아니라 약 5~6배 확대 추정치로 보입니다(5·6 / 11~13 / 16~19 패턴). | 절대값은 쓰지 않고 비율·지수로만 해석합니다(규칙 ③). |
| ⚠ 왜곡 | 법인 결제(금액의 13~16%)와 특수 업종(강남 금액의 52.6%)이 비중을 왜곡합니다. | 법인 제외(규칙 ①), 특수 업종 8개 제외(규칙 ②). |
| 고려 | 금액은 고가 업종에 좌우됩니다. | 활동 빈도는 건수로 분석합니다(규칙 ④). |
| 고려 | 데이터2 = 데이터1에서 법인을 뺀 뒤 거주지별로 다시 집계한 것입니다(금액 원 단위 일치). | 두 데이터를 중복 집계하지 않습니다. |

## 2. 탐색 분석 — 고립 신호 (02)

| 구분 | 내용 | 결정 / 대응 |
|---|---|---|
| ⚠ 결측 | NaN은 없지만 '행이 없는' 결측이 많습니다. 10대·고령·심야 조합은 대부분 비어 있습니다(춘천 10대 관측률 17%). | 희소 집단의 비율은 불안정하니 해석에 주의합니다. |
| ⚠ 오탐 | 이상일 37일은 대부분 호우(7/16~17), 추석, 춘천 대학 방학으로 설명됩니다. | 소비 감소를 바로 고립 신호로 쓰지 않습니다 → 03에서 날씨로 검증. |
| ⚠ 오해 | 춘천 면 지역의 겨울 급감(−30~−68%)은 **전 연령이 동시에** 줄어든 것입니다. | 고령층 고립이 아니라 여름 방문객 효과로 봅니다. 연령 간 상대 변화로 판단합니다. |
| ⚠ 오해 | 청년의 심야·편의점 소비가 두드러지지만, 공식 고립률은 청년이 가장 낮습니다(19~29세 24.4%). | 소비 지표는 보조로 두고, 공식 성·연령 기본 위험 위에 얹습니다. |
| ⚠ 한계 | 카드는 가맹점 소재지 기준입니다. 강남 결제의 약 50%가 서울 밖 거주자입니다. | 카드 = '그 지역 주민의 소비'가 아닙니다. |
| ⚠ 한계 | SK는 연령 × 시간대, 연령 × 요일 교차가 불가능합니다. | 연령별 시간 패턴은 카드로만 봅니다. |
| 고려 | 일요일·명절·한파 같은 '돌봄 공백기'에 고령층 소비가 크게 줄어듭니다. | 에이전트의 사전 대응 시나리오 후보로 둡니다. |

## 3. 외부 데이터 결합 · 검증 (03)

| 구분 | 내용 | 결정 / 대응 |
|---|---|---|
| ⚠ 코드 | 같은 동이 기관마다 세 가지 코드(SGIS 8자리 · 행안부 10자리 · 서울 7자리)로 표기되고, 중간에 바뀝니다. 실제로 처음에 **신사동이 개포3동으로 잘못 연결**됐습니다. 에러 없이 결과를 바꾸는 유형입니다. | 대응표를 한 곳(`external/codes/`)에서 관리합니다. 결합 후 '연결된 동 수 = 기대 동 수'를 항상 확인합니다. |
| ⚠ 결함 | 서울 관심집단에서 일원2동(현 개포3동)·상일동은 1인가구 기반 집단이 전부 0입니다. 둘 다 이름·코드가 바뀐 동이라 원본 처리 오류로 추정됩니다. | 분석에서 제외하고 사유를 밝힙니다. 새 데이터를 받을 때마다 '동별 0값 비율'을 점검합니다. |
| ⚠ 확인 필요 | 일원2동 → 개포3동 변경이 이름만 바뀐 것인지, 경계도 바뀐 것인지 확인하지 못했습니다. | 강남구청 고시로 확인해야 합니다. |
| ⚠ 시점 | 주민등록은 2026.9 기준이라 분석 기간(2025.7~12)과 1년 차이가 납니다. | 2024.12·2025.12 기준 성·연령 주민등록과 1인세대를 확보했습니다(`external/mois/*_20241231.csv`, `*_20251231.csv`). 모델 반영은 수정안 A단계에서 합니다. |
| ⚠ 출처 | 처음 쓴 Meteostat은 기상청과의 강수 상관이 0.78~0.80이었습니다(7/17 서울 75.5mm vs 26.7mm). | 기상청 ASOS 공식 자료로 교체했습니다. 교체 후 날씨 효과가 더 크게 나왔습니다. |
| ⚠ 대표성 | 강남은 SK 유동인구가 주민 수와 무관합니다(ρ 0.08). 춘천은 대표합니다(0.89). | 강남에서는 SK를 인원수가 아니라 비율·변화로만 씁니다. |
| ⚠ **정답** | 서울 관심집단은 **SKT 추정치**이고 **연령대 안 상대 기준**(상위 2%·하위 10%)입니다. 입력(SK)과 출처가 같습니다. | 결과를 '고립 예측'이 아니라 '통신 기반 고립 지표 재현'으로 표현합니다. → **가장 큰 미해결 과제** (아래 5절) |
| ⚠ 범위 | 판단도구 13점 중 데이터로 대리할 수 있는 문항은 2점(소통·체납)뿐입니다. | 에이전트 역할을 '현장 조사 우선순위 추천'으로 한정합니다. |
| 고려 | 근거 수치 일부는 정부 발표를 인용한 언론 기사입니다. | 제출 전 원문(통계청·복지부 보도자료)으로 교체를 권장합니다. |

## 4. 학습형 비교 모델 (부록 A, 이전 04)

| 구분 | 내용 | 결정 / 대응 |
|---|---|---|
| ⚠ 정답 구조 | 정답이 연령대별 상위 2%로 정의돼 연령 간 차이가 지워져 있습니다. | 연령·성별 위험 수준은 공식 고립률(B)로 정하고, 정답으로는 '같은 성·연령 안 동 차이'만 검증합니다. |
| ⚠ 외부 구조 약함 | 주민등록 구조만으로는 설명력이 약합니다(서울 417개 동, R² 0.08, ρ 0.19). | 외부 구조(S)는 보조로 두고, SK 행동(A)을 중심 축으로 둡니다. |
| 수정 ① | S를 고정된 출발점으로 넣었더니 성능이 오히려 떨어졌습니다(0.33 < SK만 0.49). | S를 변수로 넣어 비중을 학습하게 바꿨습니다(→ 0.485). |
| 수정 ② | 처음 쓴 '상위 20% 포괄률' 지표는 모든 모델이 약 20%로 나와 비교가 안 됐습니다. 이어 동점 처리 착시(B가 1.15)도 있었습니다. | '향상도'로 바꾸고 동점은 1.0으로 처리했습니다. 이론상 최대(1.41)도 함께 표시합니다. |
| 수정 ③ | 카드 C는 정답으로 검증할 수 없는데, 가중치를 바꾸면 집단의 40%가 단계를 옮겼습니다. | 영향 범위를 ±10% 안팎으로 줄였습니다. 카드의 주 역할은 실시간 신호입니다. |
| 수정 ④ | 두 지역을 한 줄로 세우니 청년이 '주의' 이상에 한 명도 없었습니다. SK를 지역 안 순위로 썼으니 지역 간 비교도 근거가 약합니다. | **지역 내 단계 + 생애단계 내 단계**를 둘 다 냅니다. |
| 수정 ⑤ | 실시간 규칙 시험에서 감소 구간까지 평소 값 학습에 포함돼 감소가 흡수됐습니다. | 운영처럼 과거 데이터로만 학습하도록 고쳤습니다(15% 감소 탐지율 13% → 93%). |
| ⚠ 낙관 편향 | 위 수정은 모두 결과를 본 뒤 강남 21개 동으로 했습니다. | 설계를 동결(`outputs/모델설정_동결.json`)하고 **시간 분할 검증**을 했습니다. 7~9월 학습 → 10~12월의 처음 보는 동에서도 ρ 0.46(같은 기간 0.47)으로, 낙관 편향은 작았습니다. |
| ⚠ 편중 | 상위 집단이 대부분 50~60대 남성입니다(B·C의 성별 차이). | **성별 내 단계**를 추가했습니다. '심각·경계' 중 여성 집단이 강남 19% → 45%, 춘천 37% → 48%로 늘었습니다. |
| ⚠ 모델 선택 | 릿지 회귀를 쓴 근거를 심사에서 물을 수 있습니다. | 같은 조건으로 비교했습니다(엄격한 검증 기준): 라쏘 0.51, 릿지 0.46, 선형 0.45, 랜덤포레스트 0.38, LightGBM 0.31. 선형 계열이 낫고, 라쏘와 릿지는 신뢰구간이 겹쳐 **동결한 릿지를 유지**합니다. 결과를 보고 모델을 바꾸면 또 하나의 사후 수정이 되기 때문입니다. |
| ⚠ 정답 안정성 | '지난 기간 정답'으로 다음 기간을 예측하면 ρ 0.74입니다. | 모델(0.46)이 잡지 못하는 동별 고유 요인이 아직 큽니다. 개선 여지이자 한계로 기록합니다. |
| ⚠ 춘천 | 정답이 없어 강남에서 배운 관계를 옮겨 적용했습니다. 사실상 **춘천은 검증 없이** 쓰고 있습니다. | → 5절 미해결 과제 ②. |
| 고려 | 효과 크기가 작습니다(SK 지표 1표준편차당 위험 2~5%, 향상도 1.12). | 1차 선별(현장 조사 대상 추리기)로만 씁니다. |

## 4b. 지수형 첫 검증 (부록 B, 이전 04b)

| 구분 | 내용 | 결정 / 대응 |
|---|---|---|
| 결과 | SKT 정답 없이 이론으로 만든 지수가 강남 SKT 정답을 학습형만큼 맞혔습니다(ρ 0.51 vs 0.49). | 04 학습형이 SKT에 과적합된 산물이 아니라는 근거입니다. |
| 결과 | 독립 지표 수렴: 강남 1인 세대 ρ 0.62, 춘천 인구 이동률 ρ 0.61(p=0.001) | **춘천도 처음으로 독립 검증**됐습니다. |
| ⚠ 오염 | 학습형은 입력에 1인 세대 비율(구조 S)이 들어 있어, 1인 세대와의 상관이 부풀려집니다. | 검증 지표로 쓰는 변수는 입력에서 빼야 합니다(지수형은 준수). |

### 과제 ①·② 개선안: '학습형'에서 '지수형 + 다중 독립 검증'으로 (제안, 2026-10-13)

**문제의 뿌리**: 가중치를 SKT 정답(강남에만 있음)에 맞춰 **학습**했습니다. 그래서 출처가 순환되고(①), 모델이 강남에 맞춰졌습니다(②).

**전환 방향**
1. **구성 — 정답 없이 지수를 만듭니다.**
   - 지표와 방향은 이론으로 미리 정합니다. 판단도구 문항(소통·외출 결핍), 고립의 정의, 02의 탐색 결과를 근거로 씁니다.
   - 가중치는 동일 가중(또는 주성분)으로 둡니다. 정답이 없을 때 쓰는 복합지수 작성의 표준 방법입니다.
   - 값은 지역 안에서 표준화해 강남·춘천에 **같은 규칙**을 적용합니다. SKT 정답은 구성에 쓰지 않습니다.
2. **검증 — 출처가 다른 여러 지표로 교차 확인합니다(삼각검증).**
   - **수렴 타당도**: 고립과 관련된 독립 지표와 같은 방향으로 움직이는지 봅니다.
