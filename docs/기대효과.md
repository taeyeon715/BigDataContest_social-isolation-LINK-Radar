# 기대효과와 검증 상태

기존 복지체계의 위기정보 기반 선제 발굴에 지역·시점별 검토 근거를 더하는 시제품입니다. 개인의 고립 여부·위험 확률을 산출하지 않습니다.

## 계산으로 확인한 것

강남 추석 전 중장년 남성 예정 점검 후보는 22개 동 중 7개입니다(임계값 민감도 5~11개). 후보 지역 수가 줄었다는 뜻이며 업무시간 절감 실적이 아닙니다. 연휴 D-7 점검과 결제 경보 사이 9~13일 차이는 달력 점검 시점의 차이입니다. 실제 경보 38건 중 19건은 도시 전체가 함께 낮아 원인 확인 대상으로 구분했습니다. 이는 오경보 제거 성과가 아닙니다.

## 반례를 통해 수정한 것

춘천시 경로당 372곳을 원장에 더하자 고령층 세 후보 면은 Level 3에서 Level 2가 됐습니다. 추석 전 후보는 8곳, 동절기 후보는 3곳입니다. 관측 원장에 없는 자원을 서비스 부재로 해석해서는 안 됩니다. 접근성이 가깝다는 결과도 이용 가능성이나 충분한 서비스 공급을 증명하지 않습니다.

원장은 1,440건이며 고정 정답 30쌍의 k-정규화 Recall@5는 0.6733입니다. 실제 연계 성공률은 측정하지 않았습니다. 핵심 추천 10개의 공식 안내를 대조했지만 당일 운영·개별 수급 자격은 확인하지 않았습니다.

## 아직 측정하지 않은 것

실무자의 판단 시간, 빠뜨린 필수 확인사항, 적합한 연결 자원 선택, 담당자 수용도는 [사용자 비교 평가](../evaluation/user_study_20261018/프로토콜.md)로 확인합니다. 12사례·3조건의 균형 배정 자료는 준비됐고 실제 응답은 0건입니다. 절감 시간을 계산하거나 결과를 가정해 채우지 않습니다. 1차 정적 자료 비교 후 실제 대화형 업무 시범 운영이 필요합니다.

현재 결과·모집단·시점은 [현재 상태](현재상태_20261018.md)와 [숫자 사용 기준](숫자_사용_기준.md)을 따릅니다.
