# 부가 데이터 정의서

제공·외부 데이터에 우리가 **더해서 만든 항목**(정리 칸, 지표, 플래그, 기대값, 코호트, 자원 칸, 값 상태, 등급 산출 값)을 한 줄씩 적었습니다.
기준 파일은 [`부가데이터_정의.csv`](부가데이터_정의.csv)이고, 이 문서는 사람이 읽기 쉽게 줄인 것입니다. 두 파일은 같은 내용입니다.

- 도구가 만드는 지표 이름(근거 카드의 `metric`)은 모두 이 정의서에 있어야 합니다. `tests/test_extra_data_defs.py`가 코드에서 지표 이름을 모아 빠진 것이 있으면 실패합니다 (`{…}`는 연령·시간대·연휴 이름이 들어가는 자리).
- 가짜 도구(`stubs.py`, 시험·시연용) 지표도 이름이 근거 카드에 나오므로 같이 적고 상태를 "시연용(가짜 도구)"으로 표시했습니다.

## CSV 칸 (13개)

| 칸 | 뜻 |
|---|---|
| `item_id` | 고정 ID (예: D-STR-01) |
| `name` | 화면·근거 카드에 나오는 이름 (코드의 `metric=` 문자열과 같음) |
| `kind` | 정리 칸 / 지표 / 플래그 / 기대값 / 코호트 정의 / 규칙 값 / 자원 칸 / 값 상태 / 값 규칙 |
| `definition` | 계산식 한 줄 |
| `inputs` | 원천 데이터와 칸 (P = 제공 데이터, E = 외부 데이터 번호) |
| `grain` | 계산 단위 |
| `type_range` | 형식과 범위 |
| `missing_rule` | 결측·0 처리 |
| `code` | 만드는 코드 위치 (`src/bigcontest/` 아래) |
| `version` | 규칙·정리 판 |
| `used_by` | 쓰는 곳 |
| `can_say_cannot_say` | 해도 되는 말 / 하면 안 되는 말 |
| `status` | 확정 / 임시 기준 / 탐색 / 미수집 / 폐기 / 시연용 |
