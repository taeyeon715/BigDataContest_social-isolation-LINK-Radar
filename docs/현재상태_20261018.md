# 현재 결과와 검증 상태 (2026-10-18)

기준 코드: 4130806 이후 접근성·자원 보강. 규칙은 rules-v1.1로 유지했고 임계값을 결과에 맞춰 바꾸지 않았습니다.

## 접근성 재검증

춘천시 공식 경로당 현황(2026년 5월 1일 기준) 372곳을 원장에 더했습니다. 원장은 1,068 → **1,440건**입니다. 도로명주소로 좌표를 확인한 시설은 326곳, 좌표 또는 주소 상태가 미확인인 시설은 46곳입니다. 미확인 시설에는 임의 좌표를 주지 않았습니다.

| 고령층 기준 | 보강 전 거리 | 보강 후 거리 | 세 기준일 등급 |
|---|---|---|---|
| 남면 | 18.57 km | 1.07 km | Level 3 → Level 2 |
| 남산면 | 14.66 km | 2.41 km | Level 3 → Level 2 |
| 북산면 | 15.58 km | 4.10 km | Level 3 → Level 2 |

경로당은 노년층 자원이므로 **중장년 남성의 거리를 줄이지 않습니다.** Level 2는 안전 판정도 서비스 충분성 판정도 아닙니다. 거리는 대표점에서 시설까지의 직선거리이며 실제 도보·대중교통 시간, 회원 자격, 프로그램, 휴일 운영은 확인하지 않았습니다. 2026년 원장을 2025년 생활 신호와 결합한 대응 우선순위 재생입니다.

춘천 고령층 예정 점검 후보는 추석 전 13 → **8곳**, 추석 뒤 13 → **8곳**, 동절기 8 → **3곳**이며 모두 Level 2입니다. 추석 전 8개 후보 지역의 65세 이상 주민등록 인구는 11,383명, 전 연령 1인세대는 16,675세대입니다. 이 둘은 서로 다른 모집단이고 고령 1인세대 수·위험자 수·수혜자 수가 아닙니다. 기존의 'Level 3 세 곳, 고령 인구 2,557명'은 보강 전 원장 결과로 폐기합니다.

## 자원 추천과 실무 검증

고정된 기존 정답 30쌍에서 상위 5개 충족도(k-정규화 Recall@5)는 **0.6733**, 정답 전체 재현율 0.3439, 정밀도@5 0.56, Hit@5 0.90입니다. 명시적 부적격 0건, 자격 확인 필요 71건이며 이용 가능성을 보증하지 않습니다. 과거 원장의 0.7533을 현재 성능으로 사용하지 않습니다. 같은 규칙으로 현재 원장에 정답을 다시 만든 0.80은 참고값입니다(정답 514건 추가·8건 제거). 고정 정답을 덮어쓰지 않았습니다.

세 후보 면의 핵심 추천 10개에 대해 공식 안내의 기관·사업·대상·접수 경로·연락처를 대조했습니다. **당일 운영이나 개인별 수급 자격을 확인한 건수는 0건**입니다. 대표번호와 기존 수행기관 번호가 다른 남부노인복지관은 두 번호의 확인 상태를 구분해 남겼습니다.

기존 업무 대비 사용자 평가는 12사례, 3조건(구조 자료 / 전체 근거 / 전체 근거+추천·체크리스트), 36개 자료 묶음과 균형 배정표를 준비했습니다. 실제 참여자 응답은 **0건**입니다. 시간 절감·정확성 개선·현장 효과는 아직 주장하지 않습니다. 평가 자료는 정적 검토 자료의 효용을 비교하는 1차 평가이며 대화형 제품 전체 효과로 확대 해석하지 않습니다.

## 발표와 운영에서 사용할 문장

- 기존 복지체계의 선제 발굴을 보완해 지역·집단·시점의 검토 근거를 정리합니다.
- 연휴는 D-7, 동절기는 해당 월 점검입니다. 폭염 예보 연동은 후속 구현입니다.
- 예정 점검과 결제 경보의 9~13일 차이는 달력 시점의 차이이며 예측 성능·피해 예방 실적이 아닙니다.
- 필수 근거 오류는 판단을 보류합니다. 선택적 추가 근거의 오류는 그 근거를 제외하고 한계를 표시합니다.
- 입력 보호는 정해진 개인정보 형식 일부를 가립니다. 모든 개인정보 제거·저장 방지를 보장하지 않습니다.
