# 최소 요구 성과물 대응표

주제설명자료의 최소 요구 성과물 4종과 필수 설명자료를 세부 항목별로 레포의 문서·그림·숫자에 연결합니다. 보고서 부록으로도 씁니다. 숫자는 에이전트 기본 규칙인 rules-v2.0 기준이고, v1.1 결과(R-1·R-2·M3 운영점 비교 등)는 '(v1.1)'로 표시합니다. 노트북을 다시 돌리면 링크한 리포트의 값이 기준입니다. 숫자에 붙일 모집단·조건·단위는 [숫자 사용 기준](숫자_사용_기준.md)을 따릅니다.

## 6. 정직하게 적어 둘 것

- 분류 성능은 모두 **합성 정답**입니다. 실제 고립 탐지율이 아닙니다.
- 위험도는 점수가 아니라 규칙이 정한 5단계 대응 체계(Level 0~3, 판단 보류)입니다. 모델은 규칙의 근거와 검증으로만 씁니다.
- 기대효과 숫자는 먼저 볼 칸을 좁힌 결과이고, 현장 확인 결과가 쌓이기 전에는 효과 실적으로 말하지 않습니다.
- 자원 추천 정답은 팀이 공개 원장 칸에 미리 적은 규칙을 적용해 만든 것이고, 현장 담당자 정답이 아닙니다. 0.6733은 정답 자원의 67%를 찾았다는 뜻이 아닙니다.
- 행 수(25행·9행·104행)는 기준일·집단을 합친 후보 행이라 서로 다른 동·사람 수가 아닙니다.
