## 6. 정직하게 적어 둘 것

- 분류 성능은 모두 **합성 정답**입니다. 실제 고립 탐지율이 아닙니다.
- 위험도는 점수가 아니라 규칙이 정한 5단계 대응 체계입니다. 모델은 규칙의 근거와 검증으로만 씁니다.
- 자원 추천 정답은 팀이 공개 원장 칸에 미리 적은 규칙을 적용해 만든 것이고, 현장 담당자 정답이 아닙니다.
