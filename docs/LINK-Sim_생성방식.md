# LINK-Sim 가상 데이터 생성 방식

대회 규정은 제공 데이터를 바탕으로 페르소나 기반 가상 데이터(synthetic data)를 만들어 쓸 수 있게 하고, 그때 **생성 방식 설명자료**를 내라고 합니다. 이 문서가 LINK-Sim의 설명자료입니다. 다른 가상 데이터(하락 주입, 정상 합성 시계열, 집단 장면 P1~P5, 가짜 API)는 [가상 데이터 설명](가상데이터_설명.md)에 있습니다.

> LINK-Sim으로 낸 숫자는 모두 **합성**입니다. 실제 사회적 고립을 찾은 성능이 아닙니다. 가상 사람 수(19,784명), 최소 감지 비율, 동 순위 상관(Spearman)도 모두 생성 가정에서 나온 합성 값이고, 인용할 때 붙일 말은 [숫자 사용 기준](숫자_사용_기준.md)에 있습니다.

결과 리포트: [reports/s1_LINK-Sim](../reports/s1_LINK-Sim/README.md) · 코드: `src/bigcontest/sim/` · 실행: `notebooks/s1_link_sim.py`

---

## 1. 목적

정답(누가 언제 단절 상태였나)을 아는 가상 사람을 만들고, 그 사람들의 결제·체류를 **제공 데이터와 같은 단위로 집계**해 지금 파이프라인(경보·반증·등급)에 그대로 넣습니다. 그러면 "코호트 결제가 15% 줄면 90% 잡는다"를 **"코호트 사람 몇 %가 단절되어야 신호가 생기나"**로 바꿔 말할 수 있습니다.

쓰는 곳은 네 가지입니다 (10절).
- (a) 정답 있는 평가: 최소 감지 고립 비율, 동 순위와 정답의 순위상관
- (b) 스트레스 시험: 연휴 + 한파, 카드 공급 지연, 한 달 빠짐
- (c) 원본 없는 시연: 제공 데이터 없이 API·화면을 같은 단위의 합성 자료로 돌림
- (d) M3형 이탈 분류의 학습·평가에 쓸 수 있는 정답 있는 자료. 지금 M3([M3 결과](../reports/m3_모델링결과/README.md))는 이 자료가 아니라 실제 패널에 하락을 합성 주입한 표본 7,106개로 학습·평가함

쓰지 않는 용도: 실제 고립 탐지율 주장, 실제 동·집단에 대한 인사이트, 개인 찾기.

## 3. 생성 방법

```
① 인구 합성   주민등록 (동 × 성 × 연령대 인구, 동 1인세대 수) → IPF → 1:40 축소 표본 가상 사람 19,784명 (시드 20261014, 관측된 고립 인구 아님)
② 페르소나    사람 속성(연령·성·1인 여부·동 유형) → 페르소나 7종 중 하나 + 계기 날짜(시작일·사건일·전입일)
③ 상태 전이   사람마다 A 평소 / R 위축 / W 단절, 하루 마르코프 전이. 계기(시작 뒤·연휴·겨울·한파·폭염·사건)엔 계기 행렬
④ 하루 활동   결제: 코호트 × 업종 묶음 × 일 기대 건수 → 포아송
              체류: 상태별 외출 수준 × 계절 체류 지수 → 집·활동 칸
⑤ 집계        카드 데이터2·1, 외지 손님, 통신 3종을 제공 데이터와 같은 열 이름·단위로
⑥ 파이프라인  SimDataSource (어댑터)로 기존 도구·경보·반증·등급 코드를 수정 없이 실행
```

**① IPF**: 칸 = 동 × 성 × 연령대(10대~80대+) × 1인 여부. 출발값 = 동 × 성 × 연령대 인구 × 1인 생활 사전 확률(가정값). 두 주변분포 (동, 성, 연령대) 인구와 (동, 1인 여부) 인원을 번갈아 맞춥니다(13번 반복, 칸 최대 상대 오차 3×10⁻¹⁴). 맞춘 칸 값을 40으로 나눠 확률 반올림(시드 고정)으로 가상 사람 수를 정합니다.

**④ 결제**: 코호트 c(도시 × 연령 × 성), 업종 묶음 k, 날짜 t의 기대 건수

  λ(c,k,t) = Σ_사람 [ 활동량 × 40 × 업종 비중(c,k) × 배율(페르소나, 상태(t), k) × 거주(t) ] × exp( 요일 + 월 + 공휴일 + 연휴 + 연휴 직전 + 폭염 + 한파 + 강수 + 도시 공통 잡음 + 코호트 잡음 )

- 활동량: 사람마다 감마(모양 2, 평균 1). 가상 1명은 실제 40명 묶음이라 하루 기대 결제 40건으로 둡니다(절대 수준은 맞추지 않음).
- 요일·월·연휴·날씨 효과: 실제 코호트 시계열 log(결제+1) 회귀 계수(`targets.json`). 월 효과는 달 가운데를 잇는 선형 보간으로 매끈하게 하되, 달 평균이 회귀 값과 같도록 매듭 값을 풉니다.
- 잡음: 도시 공통 AR(1) + 코호트 AR(1). 크기·자기상관을 6번 반복 보정 (6절).
- 건수 = 포아송(λ). 사람별 포아송의 합은 합의 포아송과 분포가 같아 코호트 단위에서 뽑습니다. 고정한 균등 난수표로 역누적분포를 쓰므로 주입 전후가 같은 잡음으로 짝지어집니다.
- 세부 업종(MCT_RY_CD)은 묶음 안 비중으로, 카드 데이터1 시간대는 도시 × 연령 × 월 비중으로 다항 분할합니다.

**④ 체류(통신)**: 사람의 하루 흐름 = 상태별 외출 수준 × 거주 × 계절 체류 지수(도시 × 동 유형 × 60대+ 여부 × 월, 날씨·상태가 바꾼 달 평균을 다시 맞춤) × 폭염·한파 날 60대+ 0.85. 흐름의 40%는 집 칸, 60%는 활동 칸에 둡니다. 칸은 동 중심점 둘레에 만든 **가상 50m 칸**이고(`BLOCK_CD` 9번째 자리 `9`), 동 × 성연령 구성비를 실제 집계에 맞춰 가중합니다(통신 체류에는 통근·방문이 섞여 있음). 가상 주민이 없는 칸(작은 면의 청년 등)은 실제 구성비만큼 '방문 체류'를 활동 칸에 더합니다.

## 5. 정답(label) 정의

- 사람 단위: 그날 상태가 **W(단절)** = 합성 정답의 '단절 상태'. 고립의 대리 상태일 뿐 실제 고립 판정 기준(고독사 위험자 판단도구 등)과 같지 않습니다.
- 코호트·동 단위: 단절 상태 비율(사람 수 ÷ 그 집단 가상 사람 수)과 인원(× 40).
- 주입 정답: `inj_w_frac`(주입한 사람 중 W ÷ 코호트 사람 수), `exp_drop`(잡음 없는 기대 결제 감소율 1 − λ_f/λ_0), `label_deviation`(exp_drop이 자기 첫 28일보다 5%p 이상 큼).

| 업종 묶음 비중 | 카드 데이터2 | 그대로 입력 | TVD 최대 0.006 |

미리 정한 통과 기준(요일 상관 ≥ 0.9, 공휴일 차 ≤ 0.05, 월 차 ≤ 0.03, MAD 비 0.8~1.25, lag-1 차 ≤ 0.1, 업종 TVD ≤ 0.02)을 **코호트 28개 중 25개**가 통과했습니다. 못 넘은 3개: 춘천 60대 남성(lag-1 차 0.12), 춘천 80대+ 남·녀(월 효과 차 0.045·0.036). 결제가 적은 코호트입니다.

## 8. 한계

- **페르소나 배율·전이 확률·배정 확률은 가정값**입니다. 최소 감지 비율 같은 결과는 이 가정에 따라 달라집니다. 실제 고립된 사람의 결제가 얼마나 줄어드는지 잰 자료는 없습니다.
- 한 해 6개월(2025-07~12)만 보고 맞췄습니다. 계절 반복, 다른 해의 연휴 모양은 모릅니다.
- 카드 건수는 연령별 배율값이라 **절대 수준은 맞추지 않았습니다**. 같은 코호트 안의 상대 모양만 맞습니다.
- 카드 데이터2는 그 시도에 사는 모든 고객이지만, 가상 사람은 그 도시 주민만입니다(다른 시군 거주 고객은 없음).
- 합성 잡음은 정규 AR(1)이라 실제보다 꼬리가 얇습니다 → 합성에서 헛경보가 덜 납니다.
- 1인 생활 사전 확률의 연령 배분은 가정값을 따릅니다 (동 총량만 정확).
- 통신 칸은 동 중심점 둘레의 가상 칸이라 격자 단위 분석(핵심 주거 격자 고르기 등)은 실제와 다를 수 있습니다. 통근·방문 인구는 구성비 가중으로만 반영했습니다.
- 동 순위 평가의 정답은 "1인 구조가 고립 부담을 따른다"는 생성 가정에서 나옵니다(시나리오 A). 이 상관은 규칙의 실제 성능 근거가 아닙니다.

### 정답 있는 자료 형식 (M3형 이탈 분류용, `link_sim_labeled_v1`)

한 행 = 시나리오 × 날짜 × 코호트. 시나리오마다 코호트 하나(`is_target`)에 페르소나를 비율만큼 주입하고, 나머지 27개 코호트는 배경 그대로입니다(도시 공통 변화 계산에 필요).

| 열 | 형 | 뜻 |
|---|---|---|
| `scenario_id` | int | 시나리오 번호 (0~119) |
| `date` | datetime | 2025-07-01~12-31 |
| `city`, `age_g`, `SEX_CCD` | str | 코호트 (경보 패널 열과 같음) |
| `sim_pay_index` | float | 합성 일 결제건수 (원천 값 아님, 수준은 의미 없음) |
| `is_target` | bool | 주입한 코호트 |
| `inj_persona` | str | S1~S7 또는 "없음" |
| `inj_fraction` | float | 코호트 가상 사람 중 바꾼 비율 (0, .02, .05, .1, .2, .3) |
| `onset_date` | datetime | 계기 시작일 (주입 코호트만) |
| `inj_w_frac` | float | 그날 주입 사람 중 W ÷ 코호트 사람 수 |
| `exp_drop` | float | 기대 결제 감소율 1 − λ_f/λ_0 |
| `label_deviation` | bool | 정답 '이탈': exp_drop − 첫 28일 exp_drop 중앙값 ≥ 0.05 (은둔 청년처럼 처음부터 낮으면 False) |
| `bg_w_frac` | float | 배경 페르소나 포함 그날 코호트 W 비율 |
| `is_holiday`, `off_block`, `heat`, `cold` | bool | 공휴일, 연휴 묶음, 폭염, 한파 |
| `data_source` | str | 항상 "synthetic" |

`bigcontest.sim.inject.wide(panel, scenario_id)`가 한 시나리오를 경보 패널 입력 모양(날짜 × (도시, 연령, 성))으로 바꿉니다. 학습·평가를 나눌 때는 **시나리오 단위**로 나눕니다(같은 시나리오의 날짜는 독립이 아님). 지금 경보 규칙의 기준 성능은 리포트 6절에 있습니다(고립 진행형 재현율 5.3%, 건강 악화형 48.8%, 연휴 단절형 73.3%).

## 10. 개인정보 안전성

- 입력은 공개 통계(주민등록·날씨·공휴일·행정동 좌표)와 제공 데이터의 **집계 통계**(비율·로그 효과·흔들림 크기)뿐입니다. 제공 데이터 자체도 이미 비식별 집계이고, LINK-Sim은 그 행을 복사하지 않습니다.
- 가상 사람 속성은 임의 ID(`SIM-…`), 행정동, 성, 10년 연령대, 1인 여부, 동 유형, 페르소나, 활동량뿐입니다. 이름·1세 나이·주소·실제 ID는 만들지 않습니다.
- 가상 1명은 실제 약 40명의 묶음이고, 칸 안에서 확률 반올림으로 뽑힌 것이라 **어떤 행도 특정 실제 사람과 대응하지 않습니다**. 가상 사람이 속한 실제 칸(동 × 성 × 연령대)은 최소 18명이고, 10명 미만 칸에 속한 가상 사람은 없습니다.
- 합성 결제·체류의 날짜별 흔들림은 실제와 상관이 없습니다(중앙값 −0.001). 같은 것은 요일·공휴일·날씨처럼 모두가 아는 달력 효과입니다.
- 개인정보보호위원회 합성데이터 안내(2024)의 유용성·안전성 검증 틀과 영국 ONS·FCA의 충실도·유용성·안전성 세 축을 따랐습니다. 원천이 집계라 재식별 공격 평가 대신 입력 목록·칸 크기·잔차 상관으로 확인했습니다.

해석 주의
- 모든 숫자에 "합성"을 붙입니다. 실제 자료 결과와 같은 표·같은 문장에 섞지 않습니다.
- 정답은 가정한 페르소나가 만든 정답입니다. 가정이 바뀌면 숫자도 바뀝니다.
- 합성의 배경 경보율이 실제보다 낮으므로 합성으로 낸 헛경보 숫자는 낙관적입니다.
- 실제 배경 + 가상 변화량(하이브리드) 결과를 주로 인용하고, 완전 합성 배경 결과는 비교용으로 둡니다.
