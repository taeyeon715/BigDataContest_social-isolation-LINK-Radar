68개 점검 항목 원문은 확인하지 못했습니다. 아래 표는 항목 번호가 아니라 **6가치 단위**로 맞췄고, 원문을 받으면 항목 번호를 붙일 예정입니다.

LINK-Radar는 개인을 판정하지 않고 **행정동 × 생애단계 집단**의 점검 순서를 정합니다. 복지대상자 선정 자체는 아니지만, 위험예측과 가까운 업무이므로 윤리기준의 요구를 같은 수준으로 맞춥니다.

## 남은 것

- 윤리기준 68개 점검 항목 원문을 받아 항목 번호별 대응표로 바꾸기 (지금은 6가치 단위)
- 이의·정정 "반영" 기록을 규칙 평가 리포트(`notebooks/r1_level_rules.py`)가 자동으로 읽게 하기 (지금은 API 목록 `GET /objections?status=반영`을 사람이 봄)
- 인공지능 기본법 시행령 현행 문구 확인 (개인 대상 결정이 아니라 고영향 해당 가능성은 낮다고 봄, 미확인)
